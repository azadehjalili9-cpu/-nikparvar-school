# مدرسه هوشمند نیک‌پرور — نسخه اولیه

## امکانات
- ثبت‌نام دانش‌آموز پایه ششم با وضعیت «در انتظار تأیید»
- تأیید یا رد درخواست توسط معلم
- ورود مجزای معلم و دانش‌آموز
- ثبت نمرات ۰ تا ۲۰ و نمایش در کارنامه
- میانگین ساده نمرات ثبت‌شده
- حضور و غیاب
- انضباط و تشویق
- انتشار تکلیف برای کلاس
- ارسال پیام به همه یا یک دانش‌آموز
- ذخیره دائمی اطلاعات در SQLite (`nikparvar.db`)

## پیش‌نیاز
Python 3.11 یا 3.12 و اینترنت برای نصب Flask و بارگذاری فونت وب (در صورت نبود اینترنت، فونت جایگزین می‌شود).

## اجرای برنامه در ویندوز
1. فایل ZIP را از حالت فشرده خارج کنید.
2. در صورت نیاز Python را از python.org نصب کنید و گزینه Add Python to PATH را فعال کنید.
3. روی `run.bat` دوبار کلیک کنید.
4. مرورگر را در نشانی `http://127.0.0.1:5000` باز کنید.
5. بار اول از پیوند «ساخت حساب معلم» استفاده کنید و حساب معلم را بسازید.
6. دانش‌آموزان ثبت‌نام می‌کنند؛ معلم باید درخواست‌ها را تأیید کند.

## ساخت EXE
روی `build_exe.bat` دوبار کلیک کنید. خروجی در `dist\NikParvarSmartSchool` ساخته می‌شود.
این نسخه با حالت onedir بسته‌بندی می‌شود تا وابستگی‌های Flask و فایل پایگاه داده قابل مدیریت باشند.
برای اجرای خروجی، پوشه ساخته‌شده را کامل نگه دارید؛ فقط فایل EXE را جدا نکنید.

## نکات مهم
- این نسخه برای اجرا روی همان رایانه (localhost) طراحی شده است. دانش‌آموزان از خانه یا گوشی‌های دیگر به آن دسترسی ندارند.
- برای استفاده هم‌زمان از راه دور، باید برنامه روی سرور امن اینترنتی یا شبکه مدرسه نصب شود و دامنه، HTTPS، پشتیبان‌گیری و تنظیمات امنیتی تکمیل شوند.
- دیتابیس شامل اطلاعات دانش‌آموزان است؛ فایل `nikparvar.db` را در اختیار افراد غیرمجاز نگذارید.
- رمزها به صورت هش‌شده ذخیره می‌شوند. کلید نشست تصادفی است؛ برای استقرار واقعی مقدار ثابت و محرمانه `NIKPARVAR_SECRET_KEY` تنظیم کنید.
- کارنامه فعلاً میانگین ساده نمره‌های ثبت‌شده را نشان می‌دهد؛ وزن‌دهی، ضریب درس‌ها و قواعد رسمی ارزشیابی باید با نظر مدرسه تنظیم شود.


## نصب روی گوشی (PWA)
این نسخه دارای manifest و service worker برای نصب به شکل PWA است. برای نصب واقعی روی گوشی از دامنه اینترنتی دارای HTTPS استفاده کنید؛ PWA روی آدرس عمومی بدون HTTPS نصب‌پذیر نیست (به‌جز localhost). دانش‌آموز لینک سایت را در Chrome اندروید یا Safari آیفون باز می‌کند و از گزینه Add to Home Screen / افزودن به صفحه اصلی استفاده می‌کند.

نکته امنیتی: نسخه فعلی برای آزمایش است و هنوز برای انتشار عمومی مدرسه آماده نیست. پیش از استفاده با اطلاعات واقعی باید روی هاست امن مستقر شود، SECRET_KEY ثابت و محرمانه تنظیم شود، پشتیبان‌گیری و محدودیت دسترسی‌ها بررسی شود و مجوز مدرسه/والدین برای پردازش اطلاعات دانش‌آموزان گرفته شود. صفحات و اطلاعات ورود عمداً در حافظه آفلاین مرورگر ذخیره نمی‌شوند.
